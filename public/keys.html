API keys

Add your own key to get real answers. Your key pays only for messages you send, in any room. Nobody else can see it or use it.

This connection isn't secure enough for keys. You opened PromptCollab over plain http:// on a network address, so anyone on the same Wi-Fi could read a key as you paste it. Add keys on the computer running PromptCollab (at localhost), or once the site has https://.

How your keys are protected

  • Encrypted on the server (AES-256-GCM) and never shown again. You only see the last 4 characters.
  • Checked before saving: the provider confirms the key works.
  • Only sent to the company that made it, and only when you press Send or Regenerate.
  • Hidden from error messages that the rest of the room can see.
  • Set a spending limit with each provider (links above), so a mistake can never cost more than you're comfortable with.
