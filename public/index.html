    How it works

    From blank page to answer in three steps

    1. 1

      Start a room

      Give it a name, then share the link or add teammates by username. They show up the moment they open it.

    2. 2

      Write it together

      Everyone types in the same prompt at once and sees each other's cursors, like a shared doc.

    3. 3

      Send and read together

      Pick a model and press Send. The answer streams in for the whole room, and the conversation stays saved.

    Features

    Built for writing prompts as a team

    Live co-editing

    See teammates' names, cursors and edits as they type. No more pasting drafts into chat and merging feedback by hand.

    Any model, one menu

    OpenAI, Anthropic, Google, and hundreds more through OpenRouter. The whole room sees which model is picked.

    Free models to start

    Try OpenRouter's free models with a free key of your own, or with a few free messages a day when the site offers them.

    Your keys stay yours

    API keys are encrypted and never shown again. Your key only pays for the messages you send.

    Code and math that read well

    Code blocks with a Copy button, tables, LaTeX equations, and export to Markdown when you're done.

    Sharing you control

    Rooms start private. Add people by username or open the room to anyone with the link, and approve requests to join.

    FAQ

    Common questions

    Is it free?

    PromptCollab itself is free. Paid AI models (like GPT, Claude or Gemini) are billed by the company that runs them, to the API key of whoever presses Send.

    You can also use OpenRouter's free models, which cost nothing, and a built-in demo model that doesn't send anything anywhere.

    Who pays when someone presses Send?

    The person who presses Send. Their own API key is used for that message, and nobody else's. If you don't have a key for a model, you can't send to it, but you can still edit the prompt and read every answer.

    Do my teammates need their own keys?

    Only to send. Anyone in the room can write the prompt and read the replies. If one person has a key and the others don't, that person presses Send when the team is ready. Each key only ever pays for its owner's messages.

    Is my API key safe?

    Keys are encrypted (AES-256-GCM) before they're saved, never shown again after you add them (only the last 4 characters), and never sent to other people's browsers. The site only accepts keys over a secure connection. You can remove a key at any time.

    Tip: set a monthly spending limit on your key in the provider's dashboard, so a mistake can never cost much.
